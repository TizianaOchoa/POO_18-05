# 💻 Actividad SOLID en TypeScript

## 📚 Descripción

Este repositorio contiene la resolución de una actividad práctica sobre los principios SOLID desarrollada en TypeScript para la materia Programación Orientada a Objetos.

La actividad consistió en analizar ejemplos de código que incumplían distintos principios SOLID, identificar los problemas de diseño y aplicar las correcciones correspondientes utilizando buenas prácticas de programación orientada a objetos.
